# Sklep Groszek — Kowary, Pocztowa 6

Oficjalna strona wizytówka sklepu **Groszek** w Kowarach przy ul. Pocztowej 6.

## Zawartość strony
- **Motyw**: Nowoczesny, ciemnozielony design dostosowany do identyfikacji wizualnej marki Groszek.
- **Logo**: Wyśrodkowane w górnym nagłówku (czerwona kropka + żółty napis Groszek).
- **Nawigacja**: Rozwijane menu z sekcjami:
  - *O nas*
  - *Kontakt*
  - *Lokalizacja*
- **Sekcja Hero**: Wyróżnione kluczowe atuty sklepu:
  - Regularne dostarczanie produktów
  - Świeże pieczywo każdego ranka
  - Bogaty asortyment alkoholi i napojów
  - Wyroby tytoniowe i akcesoria
  - Wizualizacja witryny sklepu (`sklep.svg`) z automatycznym wsparciem dla zdjęcia (`image.jpg`)
- **Dane kontaktowe**: Telefon (+48 75 718 21 82), e-mail oraz szczegółowe godziny otwarcia.
- **Lokalizacja**: Adres `Kowary 58-530, Pocztowa 6` wraz z interaktywną mapą i odnośnikiem do nawigacji Google Maps.
- **Responsywność**: Pełna obsługa urządzeń mobilnych, tabletów i komputerów stacjonarnych.
